# 1.5.0

## 中文

1.5.0 把大纲拆成「粗纲 → 细纲」两层，并让人物可以跟着细纲一起长出来。

### 两层大纲

- **粗纲**只管方向，不含任何人名，一段覆盖多少章由模型根据这段剧情的分量自己判断（20–200 章之间），不再按固定批大小切分。
- 粗纲可以在还没有角色名单时就生成；它只依赖故事前提和世界观。
- 架构页新增粗纲面板：`AI 生成粗纲`、`从现有细纲反推粗纲`、逐段`确认此段`、`按本段生成全部细纲`、`改这一段`、`从本章之后重来`。
- **细纲**仍是每章一段，但现在严格按一个已确认粗纲段来生成。生成区间落在段内时，会保留整份大纲的前缀与后续章节，不再只能从第 1 章整本覆盖。
- 面板同时显示两层进度：粗纲写到第几段、第几章，细纲写到第几章。

### 分段确认

- 段尾两个按钮可随时切换：`等我确认` 每段停下，`跳过确认` 自动逐段铺到全书。
- 选择「等我确认」时，必须先确认当前段，才会继续生成下一段或按段生成细纲。

### 对话式修改

- 改某一段：用自然语言说明方向，模型重写整段标题、形态与正文；段区间保持不变，后续段标记「待重生成」。
- 从某章之后重来：依次重写该章所在段及其后所有段。
- 改粗纲后，该段已生成的细纲会被标记为过期，界面列出需要重生成的章号。
- 改细纲：作者的改动即权威，直接保留，不弹窗、不阻塞。

### 人物可以被模型自己增删改

细纲生成改为工具循环，模型可以在写细纲的过程中自行决定要不要加人、改人、删人，并主动查人物、查知识库、查架构。暴露的工具包括：

`read_characters`、`create_character`、`update_character`、`delete_character`、`search_knowledge`、`read_architecture`。

### 生成过程可观测

- 侧栏「设置」旁新增平级的`日志`入口。
- 每次模型调用默认折叠，展开后可查看**完整 Prompt**、**完整返回**。
- 每次工具调用单独列出工具名、参数与返回内容，排查问题时能看到模型到底查了什么。

### 连贯性

- 细纲每章提交后写入结构化章节摘要与角色状态，作为后续批次的连续性记忆。
- 生成新批次时会注入最近章节摘要，并检测连续多章开场结构、固定班底高度相似的情况，及时提醒换一种推进方式。

### 修复

- 修复粗纲的惰性扩展表会改变项目 schema 指纹、导致既有项目（如《源起》）无法打开的问题。扩展表现在不参与项目格式指纹，旧项目可直接打开。
- 修复按段覆盖细纲时会把本批当成整本从第 1 章重写的问题。

下载下方 `ai-novel-writer-setup-1.5.0.exe` 安装即可。已有作品数据不受影响。

## English

1.5.0 splits the outline into two layers, arc outline and chapter outline, and lets characters grow alongside the chapter outline.

### Two-layer outline

- **Arc outline** sets direction only and never contains proper character names. The model decides how many chapters a segment spans (20-200) based on how large that dramatic proposition is, instead of using a fixed batch size.
- The arc outline can be generated before a cast exists; it depends only on the premise and worldbuilding.
- The architecture page gains an arc panel: `Generate arc outline`, `Derive from existing outline`, per-segment `Confirm segment`, `Generate all chapter outlines in this segment`, `Revise`, and `Regenerate after this chapter`.
- **Chapter outline** is still one entry per chapter, but it now generates strictly within one confirmed arc segment. When the range falls inside a segment, the surrounding outline is preserved instead of requiring a full rewrite from chapter 1.
- The panel shows both progress layers: how far the arc outline and the chapter outline have reached.

### Per-segment confirmation

- Two buttons can be switched at any time: `Wait for me` stops after each segment, `Skip confirmation` fills the book automatically.
- In wait mode the current segment must be confirmed before the next segment or its chapter outlines can start.

### Dialogue-driven revision

- Revise a segment: describe the direction in natural language. The model rewrites the segment title, beat and body; the range stays fixed and later segments are marked for regeneration.
- Regenerate after a chapter: rewrites the segment containing that chapter and every later segment in order.
- After an arc change, chapter outlines built from that segment are marked stale and listed in the UI.
- Editing a chapter outline is authoritative: changes are kept without prompts or blocking.

### Characters managed by the model

Chapter-outline generation now runs a tool loop, so the model can decide to add, update or delete characters while writing the outline, and can look up characters, knowledge and architecture on its own. Exposed tools:

`read_characters`, `create_character`, `update_character`, `delete_character`, `search_knowledge`, `read_architecture`.

### Observable generation

- A new `Logs` entry sits beside Settings in the sidebar.
- Each model call is collapsed by default; expanding it shows the **full prompt** and **full response**.
- Every tool call is listed with its name, arguments and returned content.

### Continuity

- Each committed chapter outline writes a structured chapter digest and character state as continuity memory for later batches.
- New batches receive recent chapter digests and detect repeated opening structures with the same fixed cast, warning the author to vary the approach.

### Fixes

- Fixed lazy arc extension tables changing the project schema fingerprint and preventing existing projects (such as 源起) from opening. Extension tables no longer participate in the project format fingerprint.
- Fixed segment-based chapter generation rewriting the whole outline from chapter 1.

### Installation

Download `ai-novel-writer-setup-1.5.0.exe` below. Existing project data is untouched.

The Windows installer is not code-signed; Windows may warn about an unknown publisher.
