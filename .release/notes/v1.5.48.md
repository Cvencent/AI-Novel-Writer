# 1.5.48

## 中文

### 写作智能：编辑部评审、候选锦标赛、角色声音、事实账本

- 新增**编辑部评审**：情节、连续性、角色、文风、节奏五路独立评分，带证据与阻断标记，结果写入这份草稿的质量记录，重开页面仍在。
- 新增**候选锦标赛**：用同一套五角色标准给同一章的多个版本打分排名。启动时冻结章节与候选集合，只有本次运行的结果会结算回界面。
- 新增**角色声音档案**：从定稿正文提取可复用的对白特征（句式、用词、对白习惯、情绪表现、应避免的表达），展示在角色档案里。
- 新增**事实账本**：定稿后记录事实、角色状态、伏笔与质量分。旧项目若已有定稿，可以直接「从当前投影重建」。
- 新增**场景卡编辑**：把本章蓝图拆成目标—阻力—转折—结果明确的场景。

### 按功能分配模型

- 设置里新增**「功能模型分配」**：粗纲生成、细纲生成、蓝图生成、正文生成、粗纲审核、细纲审核、蓝图审核、正文审核、编辑器 AI、AI 助手对话，每项都能单独指定模型；未指定的跟随默认模型。
- 运行时按「功能配置 → 全局默认 → 任一生成模型」解析，设置里直接显示每个功能当前实际使用的模型。

### 修复：异步任务与页面切换

- **编辑部评审、角色声音、候选锦标赛**都会清楚显示进度与结果，切换页面再回来不会串到别的草稿：切换时立即作废旧请求，迟到的结果不会覆盖当前内容；只有本次启动的任务完成时才会刷新界面。
- 止住了「点了开始但按钮一直转」的问题：任务启动被拒绝或失败时，按钮都会回到可再次点击的状态。
- 运行诊断页会区分「未上报用量」「模型缺价格」「调用失败且无用量」三种无法估算费用的原因，不再笼统显示「缺价格或用量」。

### 修复：AI 检查与卡片持久化

- AI 检查完成后会真正带着分数、五路结论与建议卡片显示，而不是「跑完了但什么都没有」。
- 一键清除卡片与单张移除都会落库，切换页面或重启后不再自动冒出来。

## English

### Writing intelligence: editorial panel, candidate tournament, character voice, fact ledger

- New **editorial panel**: independent scores for plot, continuity, character, style, and pacing, with evidence and blocking flags written to the draft's quality record and preserved across page changes.
- New **candidate tournament**: score several versions of one chapter with the same five-role rubric. The chapter and candidate set are frozen at launch, and only that run settles the UI.
- New **character voice profiles** extracted from finalized prose and shown on the character profile.
- New **fact ledger**: records facts, character states, foreshadowing, and quality after finalization. Older projects with a finalized chapter can rebuild it from the current projections directly.
- New **scene-card editing** that splits a chapter blueprint into goal–resistance–turn–outcome scenes.

### Per-function model assignment

- Settings now has a **Function models** page: outline generation, detailed-outline generation, blueprint generation, chapter writing, outline review, detailed-outline review, blueprint review, chapter review, Editor AI, and assistant chat each take their own model; unassigned functions follow the default.
- Resolution is "function config → global default → any generation model", and the page shows the model each function is actually using.

### Fixes for async tasks and page changes

- Editorial panel, character voice, and candidate tournament now show progress and results reliably and never leak across drafts: switching invalidates in-flight requests, late replies cannot overwrite the current view, and only the launched run refreshes the UI.
- Fixed the "started but the button spins forever" case: the button returns to clickable when a launch is rejected or fails.
- Run diagnostics now distinguish "no usage reported", "model has no price", and "failed call with no usage" instead of a vague "missing price or usage".

### Fixes for AI checks and persisted cards

- AI checks now actually render scores, five-role findings, and suggestion cards instead of finishing with nothing to show.
- Clear-all and per-card removal persist, so cards no longer reappear after switching pages or restarting.
