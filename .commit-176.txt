feat(consistency): 「核对物证形态」覆盖「参照物落空的物件比对」 (issue #176)

现场：第 80 章一句台词把温珩取走的油布包与「你爸票夹里那件」相比——
而全书 81 章里「票夹」出现过 **20 章**，装过的**全是平的纸件**（空白票根/存根册/纸条/收条/半截铅笔），
「油布包」全书只在 **ch37**（温珩从自己短褂夹层抽出）与 **ch80** 出现，「包法」全书**仅 ch80 一处**。

本机只读副本复核完全一致：`油布包 = [37,80]`、`包法 = [80]`、`票夹 = 20 章`、ch80 那句逐字在。

这个参照物**从未被建立**，而这句正是本章后段「油布包下落不明、等温珩现身再问」的支点。
而且它被三层继承：蓝图 `key_events`「包法同父亲旧票夹里那件」→ 正文照抄 → `chapter_commits.facts_json` 收下。

按 issue 建议 ②（扩已有判据、不新起机制）：

- `EVIDENCE_SHAPE_KINDS['same-object-drift']` 中英再扩一层：**或一句话把某件东西拿去和
  「前文某处的东西」比（「跟 X 一样」「和上次那只同一件」），而那个参照物从来不存在、
  或里面装的不是这种东西**。
- `buildEvidenceShapePrompt` 中英各加一条判法：一句话说「跟某处那件一样」时，
  要核参照物**在前文是否真的存在、且里面装的/包的是不是这种东西**；
  参照物不存在、或它装的东西根本不同类（**票夹里只有纸，却被拿来说明「包法」**），就要报。

⚠️ 与 #167 的分界：这一句里**没有记忆动词**，`memoryCallbackSentences` 取不到它
（我实测第 80 章返回 0 条），所以它落在「物件比对」这一档而不是「记忆回指」那一档。
⚠️ 与 #38 / #78 / #113 / #122 的分界：那些判「交接缺失」「物证复活」，本条判**参照物从未被建立**。

⚠️ issue 建议 ①（建「物件—首次出现章—持有者」表）本轮没做：那是新表 + 新 schema，
而建议 ② 能先把「错了会被报出来」做到；真要建表，形态字段必须由模型填，不能由规则从正文抽。
