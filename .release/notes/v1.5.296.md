# 1.5.296

## 中文

这一版集中加固了本地数据安全与审稿输入容量，并跟随编辑部评审/生成恢复路径继续迭代。

### 本地数据安全

- 模型 API 密钥改用系统密钥库（Electron safeStorage）加密落盘：有 OS 密钥库时密文存储、读取时解密；无密钥库的环境保持原有明文行为，不阻断使用。
- 预加载桥接改为 IPC 通道白名单：只有登记在册的通道才能 invoke/订阅，未登记通道一律拒绝，缩小渲染进程可触达的主进程接口面。白名单由脚本从通道定义与注册点自动生成，并有同步测试防止漂移。
- 供应商错误日志落盘前脱敏：抹掉 API 密钥、`sk-` 令牌与 `Bearer` 凭据，并截断超长错误，避免密钥随错误记录泄露。
- 全局配置补丁增加防御：拒绝非对象补丁；`proxy` 等嵌套对象按子字段深合并，不再因浅合并丢掉未提交的默认子字段。
- 知识库检索入口校验 topK 与章节范围参数，拒绝越界/非法注入。

### 审稿与生成

- 修复审稿提示词把「作者重点检查维度」重复渲染进可选侧重段、导致前驱正文被重复计入输入容量的问题：focus 统一由哈希校验的作者材料块承载，普通审稿与复核两路一致，不再触发容量溢出。
- 复核提示词钉死 JSON 形状（逐字样本 + 点名禁用键），降低一次性复核输出被整份拒收的概率。
- 编辑部评审、finalize 重试与 legacy 名册补标继续跟随修复。

### 验证

- 全量测试、类型检查、lint、i18n 覆盖率检查通过。

本版不含 schema 迁移，不修改作品内容。

Windows 安装包未签名。

## English

This release hardens local data security and review input capacity, and continues iterating on the editorial review / generation recovery paths.

### Local data security

- Model API keys are now encrypted at rest with the OS keyring (Electron safeStorage): ciphertext storage with decryption on read where a keyring is available; environments without a keyring keep the prior plaintext behavior so nothing is blocked.
- The preload bridge now uses an IPC channel allowlist: only registered channels can be invoked/subscribed; undeclared channels are rejected, narrowing the main-process surface reachable from the renderer. The allowlist is generated from channel definitions and registration sites, with a sync test to prevent drift.
- Provider error logs are redacted before persistence: API keys, `sk-` tokens and `Bearer` credentials are stripped and overlong errors truncated, so keys cannot leak through error records.
- Global config patches are validated: non-object patches are rejected; nested objects such as `proxy` are deep-merged per subfield so uncommitted defaults are no longer dropped by a shallow merge.
- Knowledge-base search validates topK and chapter-scope parameters, rejecting out-of-range/invalid injection.

### Review and generation

- Fixed the review prompt rendering the author review focus twice (into the optional emphasis section), which double-counted predecessor text against input capacity: focus is now carried solely by the hash-validated author material block, consistent across ordinary review and recheck, no longer triggering capacity overflow.
- The recheck prompt pins the JSON shape (verbatim sample + explicitly forbidden keys), reducing the chance a one-time recheck output is rejected wholesale.
- Editorial review, finalize retry and legacy-roster provenance backfill continue to be fixed.

### Verification

- Full test suite, type check, lint and i18n coverage checks pass.

This release contains no schema migration and does not modify work content.

The Windows installer is not code-signed.
