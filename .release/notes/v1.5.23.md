# 1.5.23

## 中文

这一版修复角色名单被误判为异常的问题。

### 细纲推进角色状态后不再把名单弄坏
- 细纲生成会更新角色的近期事件、地点与关键物品；旧逻辑只改角色状态，没有同步刷新角色名单的事实哈希。
- 现在状态更新与名单事实哈希在同一事务内完成，下一次读取不会再把完好的角色卡误判为 `inconsistent`。

### 已有异常项目可以安全自愈
- 打开角色名单时会检查：角色图谱投影必须完全一致，才会重算过期的事实哈希。
- 自愈只更新事实哈希和修订号，不修改角色卡、关系或 `characters_arch`。
- 如果静态角色事实真的不一致，仍保持失败关闭，不会把被篡改的数据直接放行。

### 实测
- 已在《源起》项目上完成修复：8 个角色、35 条关系、角色图谱原文与投影哈希全部保持不变，名单状态恢复为 `ready`。
- 新增“细纲推进后保持 ready”和“静态事实冲突拒绝自动修复”的回归测试。

### 验证
- 类型检查、lint、i18n 覆盖率检查通过。
- 全量浏览器回归：80 个测试文件、958 项全部通过。
- 角色名单与控制器相关单元测试通过。

升级不改动作品数据。

Windows 安装包未签名，系统可能提示未知发布者。

## English

This release fixes false inconsistent states in the character roster.

### Chapter-outline state updates no longer invalidate the roster
- Chapter-outline generation updates recent events, location and key items.
- State updates and the roster fact hash now commit in one transaction, so a valid roster is not reported as inconsistent on the next read.

### Existing affected projects can self-heal safely
- On roster read, an expired fact hash is normalized only when the character-graph projection matches exactly.
- Self-healing changes only the fact hash and revision; character cards, relationships and characters_arch are untouched.
- Genuine static-fact conflicts remain fail-closed.

### Verification
- The Yuanqi project was repaired in place: 8 characters, 35 relationships, the cast projection and its hash were preserved; status is ready.
- Added regressions for outline-state updates and for refusing unsafe repairs.
- Typecheck, lint, i18n coverage and the full browser suite (80 files, 958 tests) pass.

Upgrading does not touch project data.

The Windows installer is not code-signed; Windows may warn about an unknown publisher.
