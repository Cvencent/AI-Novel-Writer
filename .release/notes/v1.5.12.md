# 1.5.12

## 中文

这一版补全「框选改写」送给模型的上下文，让它不至于盲改。

### 模型现在知道自己正在改什么

- **改的是哪一块**：核心大纲、世界观、金手指、主角人设、全局写作要求、文风、参考作品、故事前提、世界观架构、角色名单、粗纲、情节大纲、章节正文，各自带着自己的定位与一致性约束送进 prompt。
- **选区前后文**：把选中文字前后各约 240 字一并送去，改后的内容才能和相邻文字在指代、时态、称谓与节奏上自然衔接。输出仍然只要求返回选中那一段。
- **项目里的其它权威设定**：类型、细分类型、目标读者、篇幅、故事结构、叙事视角、写作语言，以及除当前字段外的其它已写设定，都会作为不得矛盾的事实带上（单条超长会截断）。

### 一致性约束按字段区分

- 世界观：守住已确立的规则、时代、力量体系与社会结构。
- 核心大纲：守住故事前提、主角目标与核心冲突。
- 文风：只改写法，不许塞剧情事实。
- 粗纲：只写走向、不落人名，章节区间保持连续。
- 章节正文：守住既有事实、视角、时间线与叙事意图。
- 其余字段各有对应约束。

作者若自定义过 edit_selected_text 模板并删掉了占位符，上述权威上下文仍会由运行时补回，不会被自定义模板吃掉。

### 验证

- 全量浏览器回归：80 个测试文件、958 项全部通过。
- 新增后端用例覆盖：作用域与前后文进入 prompt、项目权威设定进入 prompt、非法作用域在创建运行前就被拒绝、自定义模板省略占位符时仍补回上下文。
- 真实打包程序端到端：在《源起》核心大纲与世界观的框选改写链路中确认请求带上了 scope 与前后文。
- 类型检查、lint、i18n 覆盖率检查全部通过。

升级不改动作品数据。

Windows 安装包未签名，系统可能提示未知发布者。

## English

This release fills in the context sent to the model for selection rewrites so it no longer edits blind.

### The model now knows what it is revising

- **Which part it is editing**: core outline, world setting, core hook, protagonist profile, global guidance, writing style, references, premise, worldbuilding, character roster, arc outline, plot synopsis and chapter manuscript each carry their own role and consistency constraints.
- **Surrounding context**: roughly 240 characters before and after the selection are sent so the revision connects naturally in pronoun, tense, form of address and rhythm. The model is still asked to return only the selected passage.
- **Other authoritative project settings**: genre, subgenre, target readers, length, story structure, point of view, writing language and the remaining written setup fields are supplied as facts that must not be contradicted (very long fields are truncated).

### Consistency constraints are per field

- World setting: keep established rules, era, power system and social structure.
- Core outline: keep premise, protagonist goal and central conflict.
- Writing style: change the writing, never introduce plot facts.
- Arc outline: direction only, no proper names, contiguous chapter coverage.
- Chapter manuscript: keep established facts, viewpoint, timeline and intent.
- Every other field has its own constraint.

If the author customised the edit_selected_text template and removed the placeholders, the runtime still appends this authoritative context instead of letting the custom template swallow it.

### Verification

- Full browser regression: 80 test files and 958 tests passed.
- New backend coverage: scope and context reach the prompt, authoritative project settings reach the prompt, an unknown scope is rejected before any run is created, and a custom template that omits the placeholders still receives the context.
- Packaged end-to-end run confirmed the request carries scope and surrounding context for the core outline and world setting.
- Typecheck, lint and i18n coverage all pass.

Upgrading does not touch project data.

The Windows installer is not code-signed; Windows may warn about an unknown publisher.
