# 1.5.2

## 中文

修复两层大纲在生产路径上的两个缺陷。

- **细纲提交后不写章节归属**：主进程逐章生成路径提交成功后没有调用 `db:arc-binding-bind-range`，导致粗纲改动后无法把这些章节判为 stale，「需要重新生成」提示不会出现。现在提交后按本批范围写入归属。
- **细纲提交后不写章节摘要与角色状态**：同一路径也没有写 `summary_snapshots` 与角色当前状态，后续批次读不到最近章节摘要，连贯性记忆实际失效。现在逐章写入摘要与角色状态。
- 日志页的工具调用解析补充了回归测试，确认能展示工具名、参数与返回内容。

已在测试副本上验证：确认粗纲段、按段生成细纲（两批共 20 章）、对话式重写粗纲、日志页完整 Prompt 与返回展开均正常。

其它功能与 1.5.1 一致。升级不改动作品数据。

Windows 安装包未签名，系统可能提示未知发布者。

## English

Fixes two defects in the production path of the two-layer outline.

- **Chapter outlines did not record arc ownership**: after a successful main-process chapter-by-chapter commit, `db:arc-binding-bind-range` was never called, so an arc change could not mark those chapters stale and the regeneration hint never appeared. Ownership is now written for the committed range.
- **Chapter outlines did not write digests or character state**: the same path skipped `summary_snapshots` and character current state, so later batches could not read recent chapter digests and continuity memory was effectively dead. Digests and character state are now written per chapter.
- Added a regression test for tool-call parsing in the log page, covering tool name, arguments and returned content.

Verified on a test copy: confirming an arc segment, generating chapter outlines from it (two batches, 20 chapters), dialogue-driven arc rewrite, and expanding full prompt/response in the log page all work.

All other behavior matches 1.5.1. Upgrading does not touch project data.

The Windows installer is not code-signed; Windows may warn about an unknown publisher.
