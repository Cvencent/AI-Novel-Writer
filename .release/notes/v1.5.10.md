# 1.5.10

## 中文

这一版修正 1.5.9 里选区 AI 操作的含义。

### 现在可以直接告诉 AI 怎么改

- 删除了含义不清的「改成对话」。
- 框选文字后保留 **润色 / 扩写 / 续写** 三个快捷操作，并新增「告诉 AI 怎么改」输入框。
- 可以直接输入类似「写得更紧张，删掉解释性旁白」「改成更克制的第三人称，不要新增事实」这样的要求，再点「改写」或按回车。
- AI 会把你输入的整段要求作为本次改写指令，先显示预览，确认后才替换原文。
- 设定页和故事架构编辑器使用同一套交互，行为一致。
- 旧的「改成对话」历史运行仍可读取，不会因升级损坏。

### 验证

- 全量浏览器回归：80 个测试文件、957 项全部通过。
- 新增测试覆盖自定义指令的输入、提交、预览、替换、空指令拒绝、运行恢复和提示词传递。
- 真实打包程序中已完成桌面端验收：在《源起》核心大纲和世界观中输入自定义要求、预览、替换、保存并在重启后确认内容保留。

升级不改动作品数据。

Windows 安装包未签名，系统可能提示未知发布者。

## English

This release corrects the meaning of the selection AI actions introduced in 1.5.9.

### You can now tell AI exactly how to revise the selection

- Removed the ambiguous **To dialogue** action.
- Selecting prose now shows **Refine / Expand / Continue** plus a **Tell AI how to revise** input.
- You can enter instructions such as "make this tenser and remove exposition" or "use a more restrained third person, without adding facts", then press **Rewrite** or Enter.
- The full author instruction is sent as the rewrite request. The result is previewed first and replaces the original only after confirmation.
- The setup page and story architecture editor now share the same interaction.
- Existing historical **To dialogue** runs remain readable after upgrading.

### Verification

- Full browser regression: 80 test files and 957 tests passed.
- New tests cover custom instruction entry, submission, preview, replacement, rejection of empty instructions, run recovery and prompt delivery.
- The packaged desktop app was verified end to end: custom instructions were entered for the core outline and world setting in 《源起》, previewed, replaced, saved, and confirmed after restart.

Upgrading does not touch project data.

The Windows installer is not code-signed; Windows may warn about an unknown publisher.
