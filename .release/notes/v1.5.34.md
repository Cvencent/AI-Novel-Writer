# 1.5.34

## 中文

### 修复：细纲生成到一半就失败（角色档案 / 上游抖动 / 缺小节）

之前连续出现几种「生成细纲失败」，原因各不相同，现在都已修复：

- **`GENERATION_SOURCE_CHANGED`**：细纲生成允许模型自己用 `create_character` 新建角色，但建卡会重写角色图谱投影，任务于是把**自己的合法产出**当成外部篡改而中止。现在归一化到冻结值后再比对：本任务自己建的角色不算来源变化，外部真的改了设定仍然继续拦。
- **上游 502 / 断网**：一次网络抖动会把整批细纲打断。现在这类「没有任何输出」的传输失败不再算掉本章尝试，会退避后重试；连续失败到上限才停，并给出可读原因（连接失败）而不是含糊的「AI 未正常完成」。
- **章节缺少固定小节**：模型漏写「伏笔」这类小节时，以前会推进游标后撞合成闸门、整批报错。现在按设计发起一次重建，写好就继续往下走。
- **工具轮次硬上限**：不再拍脑袋定 3/6 轮，改用生成根预算的剩余请求数，并按后续章节数预留；最后一轮固定留给收尾，模型不会把预算全花在查资料上。

### 验证

- 在《源起》（3000 章）上真实跑通：第 1–10 章、第 11–15 章（期间真实撞到上游 502 并自动恢复）、第 16–20 章全部生成完成，正式细纲共 20 章，无重复章号、无缺小节。
- 角色名单在生成过程中真实从 11 人长到 12 人，证明「生成细纲时自己加人」路径可用。
- 日志页可看到每次调用的完整 Prompt、工具调用与工具返回。
- 新增回归测试：传输失败不占章节尝试、重试上限后停下、缺小节触发 compact 重建。

## English

- Fixed three separate causes behind "plot outline generation failed": the run's own `create_character` writes are no longer treated as external source tampering; upstream 502/network drops no longer kill a whole batch (bounded, backed-off retries that never consume a chapter attempt); and a chapter missing a required section now triggers the designed rebuild instead of aborting the batch at the compose gate.
- Tool rounds now follow the real generation budget (with per-chapter reservation and a reserved final round) instead of a hardcoded 3/6 limit.
- Verified on a real 3,000-chapter book: chapters 1–20 generated end to end, including a real upstream 502 that recovered automatically.
