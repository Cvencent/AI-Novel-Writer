# 1.5.21

## 中文

- 细纲生成时，模型可以自主调用 `read_characters` / `create_character` / `update_character` / `delete_character` / `search_knowledge` / `read_architecture`。
- 新增/修改/删除角色会直接写入角色名单（intent=manual_edit），不需要额外确认。
- 本轮补齐：`create_character` 和 `update_character` 现在也能填写「人际关系」字段。
- 工具调用会写进工作流日志，可在日志页查看查了什么、改了什么。

## English

- During chapter-outline generation the model can call read_characters / create_character / update_character / delete_character / search_knowledge / read_architecture.
- Adding, updating and deleting characters writes straight to the roster (intent=manual_edit) without a separate confirmation.
- This release adds a relationships field to create_character and update_character.
- Tool calls are recorded in the workflow log so you can see what was read or changed.

The Windows installer is not code-signed.
