feat(consistency): 「核对物证形态」加第三档：保管关系突变（谁持有 / 锁没锁 / 哪个房间）(issue #182)

现场：ch78/79 柯明远亲手把铜墨盒锁进自己的私柜、**手在锁上压着没挪开**；
ch82 同一把柜子「**没锁死**」、钥匙在**管物人**腰上，保管地点还从「公所扣留处的铁柜」
挪到了「办公楼墙边」——全章**没有一句交接**。而 ch82 整章的推理（湿底湿印、指甲痕、谁动的）
全都建立在「柜子锁着、钥匙在柯明远手上」这个前提上，前提被本章自己推翻。

这一层原来**全仓没有判据**：`prop-termination` 管终结、`prop-relocation` 管容器、
`blueprint-semantic-contract` 管「必须当面易手」——没有一条比「同一件扣押物的保管人 /
锁具状态 / 所在房间」在相邻章之间有没有突变。

按 issue 建议 ②：把它加进**已存在的**「核对物证形态」判据（不新开一颗按钮、不加词表）：

- `EVIDENCE_SHAPE_KINDS` 新增第三档 `custody-drift`；
- 提示词在原来两类之外补两条边界：
  - **正文自己写出来的交接不算问题**（有人交出钥匙、房间改派、当着人撬封）；
  - 只有「同一件被扣押的实物换了保管人/锁具状态/所在房间，且**没有写任何交接**」才报。
- 三处都要问到（`保管人` / `锁具状态` / `所在房间`）——只问「谁持有」会漏掉「没锁死」和「换了房间」。
- `parseEvidenceShapeReview` 的 kind 白名单加 `custody-drift`（其余四道收窄不变：
  两个章号都要在样本内、**两处引文都要逐字可定位**、去重）。
- `evidenceShapeFindings` 给这一档**专门的文案**（「把一件被扣押的实物写成了换了保管人／
  锁具状态／所在房间，而正文没有任何交接」），而不是落进「形态对不上」的默认句。

⚠️ 这是**内容判断**（哪些算「同一个保管关系」要读懂句子），所以整档在模型侧，规则只做
「喂样本 + 校验两处引文可定位」。`no-content-wordlists` 7 例全绿（没有新增词表）。

验证：`evidence-shape-review` 16 → **20 例**：三处都要在提问里点到 / **正文自己写的交接不算** /
受理引用可逐字定位的 custody 报告 / 文案与「形态漂移」区分开。
红验证：把 `custody-drift` 从 kinds 列表里去掉 → 2 例当场红；恢复 → 20 全过。
typecheck 通过；同批 35 例全绿。
