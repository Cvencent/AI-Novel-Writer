# 1.5.25

## 中文

修复细纲被写成流水账／日记体的问题。

### 根因
- 项目文风设定（压力—应对—结算、章末结算数字）是给正文用的，却被原样注入细纲 Prompt，模型把它当成细纲排版。
- 细纲会把前几章全文当范本注入，格式被逐章自我复制放大：第 20 章干净，第 21 章起出现结算块，第 200 章已成时间戳日记。

### 修复
- 细纲合同新增明确结构要求：场景与人物 → 本章目标 → 阻力升级 → 转折或代价 → 结尾钩子。
- 明确禁止时间戳分段、逐条结算、账目清单、日记摘抄和章末结算块。
- 明确「正文文风只约束正文，不要套用到细纲排版」。
- 新增日记体检测：命中时间戳分段／结算块／账本摘抄的章节判为无效并重写。

### 验证
- 新增 4 项日记体回归测试，全部通过。
- 类型检查、lint、i18n 覆盖检查通过。

升级不改动作品数据。

Windows 安装包未签名。

## English

Fixes plot outlines being written as timestamped diaries.

### Root cause
- Prose-style guidance (pressure-response-settlement, closing numbers) was injected into the outline prompt, so the model applied it to outline layout.
- Accepted chapters are injected as examples, so the format replicated and amplified: chapter 20 was clean, chapter 21 gained a settlement block, chapter 200 was a full timestamp diary.

### Fix
- The outline contract now requires dramatic units: scene and cast -> goal -> resistance and escalation -> turn or cost -> closing hook.
- Forbidden: timestamped segments, per-item settlement lists, ledger excerpts and closing settlement blocks.
- States explicitly that prose style governs the novel prose, not the outline layout.
- Added diary-style detection; chapters matching it are rejected and rewritten.

### Verification
- 4 new regression tests pass. Typecheck, lint and i18n pass.

Upgrading does not touch project data.
