# 1.5.8

## 中文

这一版修掉粗纲生成里一个很冤的失败。

### 粗纲里出现一个人名，不再让整段作废

- 报错是 `ARC_OUTLINE_PROPER_NAME_FOUND:林越`。粗纲的规则是**只写方向、不写具体人名**（人名要留到细纲才落地），但模型偶尔会漏写出一个名字。过去的处理是：只要命中一个人名，整段生成直接抛错，工作流中断，作者白等一次模型调用还得重来。
- 现在改成：命中的名字**按角色定位换成身份词**再继续——主角 → 主角，反派 → 对手，配角 → 配角，其它或名单外的角色 → 某位角色（英文作品对应 the protagonist / the antagonist / a supporting character / a character）。「林越在学院竞赛中获胜」会变成「主角在学院竞赛中获胜」，方向语义不变，而那正是粗纲本来就该有的写法。
- 替换后会照常跑完整校验：段长、beat 多样性、章节区间连续覆盖，一条都没有放松。生成成功时日志里会写一句「粗纲里出现了人名（…），已按角色定位换成身份词」，让你知道模型这次写跑了。
- 三条粗纲生成路径都改了，不只是最常用的那条：**生成下一段**、**重写某一段**、**从已有细纲反推粗纲**。

### 验证

- 新增 7 项测试（4 项替换逻辑、3 项命令闸门），粗纲相关的 3 个测试文件共 40 项全过；`src/shared` 与 `src/services/workflows/commands` 两个目录共 62 文件 / 1218 项全过。
- 关键行为做了 red-green 验证：临时把替换逻辑改成不替换，新用例如期变红，恢复后转绿。
- 类型检查、lint、i18n 覆盖率检查全部通过。

升级不改动作品数据。

## English

This release fixes a needlessly harsh failure in arc outline generation.

### One stray character name no longer discards the whole segment

- The error was `ARC_OUTLINE_PROPER_NAME_FOUND:林越`. Arc outlines are meant to carry **direction only, no proper names** (names belong in the chapter outline), but the model occasionally leaks one. The old behaviour threw immediately on the first hit, aborted the workflow, and made you wait through a model call for nothing.
- Now the offending names are **replaced by role words** and generation continues: protagonist → 主角 / the protagonist, antagonist → 对手 / the antagonist, supporting → 配角 / a supporting character, anything else → 某位角色 / a character. "林越 wins the academy contest" becomes "the protagonist wins the academy contest" — the direction is unchanged, and that is what an arc outline is supposed to say.
- After replacing, the segment still goes through the full gate: span limits, beat diversity and contiguous chapter coverage are all still enforced. On success the run log notes which names were replaced, so you know the model slipped.
- All three arc paths are covered, not just the common one: **generate the next segment**, **rewrite one segment**, and **derive the arc outline from an existing chapter outline**.

### Verification

- 7 new tests (4 for the replacement logic, 3 for the command gate); the 3 arc-related test files pass 40 tests; `src/shared` and `src/services/workflows/commands` pass 62 files / 1218 tests.
- Red-green verified: disabling the replacement made the new test fail, restoring it made it pass.
- Typecheck, lint and i18n coverage all pass.

Upgrading does not touch project data.

The Windows installer is not code-signed; Windows may warn about an unknown publisher.
