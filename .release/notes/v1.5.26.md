# 1.5.26

## 中文

### 细纲 Prompt 不再注入正文文风设定
- 文风设定（节拍、章末结算数字、用词腔调）是给正文的，之前却被注入细纲 Prompt，模型把它当成细纲排版格式。
- 现在细纲 Prompt 明确排除 writingStyle，只保留核心大纲、前提、角色、世界观、全局写作要求与叙事约束。

### 新的项目文风：冷底子，热语气
- 保留压抑骨架：欠费、降级、配额、倒计时、代价当场兑现，数字要真。
- 叙述语气改活：主角用现代都市口语自嘲、拆台、算小账；压抑写在数字和身体反应上，不写在唉声叹气上。
- 幽默必须从规则里长出来（规则错位、数值反差、身份落差、自嘲拆台、系统一本正经的荒谬），不许硬搞笑。
- 一章点缀两到四处笑点，每四章允许一章更冷更沉，形成呼吸感；严禁谐音梗与为搞笑让角色变蠢。
- 去掉\"结尾必须写清配额增减\"的硬要求，改为\"四分之三的章节给硬数字\"，避免退化成账本体。
