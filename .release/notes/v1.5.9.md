# 1.5.9

## 中文

这一版把架构编辑器里的「框选文字后让 AI 修改」带到了作品设定页。

### 设定页的长文本都能直接框选修改

- 核心大纲，以及「更多设定」里的文风、主角人设、世界观、金手指、全局写作要求、参考作品，共 7 个长文本框，现在都支持框选文字。
- 框选后会出现和架构编辑器相同的四个操作：**润色、扩写、续写、改成对话**。提示词、推理阶段和交互也共用同一份定义，避免两个编辑器以后各改各的。
- AI 先显示预览，只有点击「替换」才写回设定；点「取消」不会改动原文。
- 如果生成期间原文被改过，旧结果不会覆盖新内容，界面会明确提示结果未应用，仍可复制预览。
- 设定页原有字号、行高、输入框样式、自动聚焦、保存与必填校验全部保持不变，只增加选区浮层。

### 验证

- 全量浏览器回归：80 个测试文件、955 项测试全部通过。
- 新增组件测试覆盖完整生成预览与替换、生成期间正文变化时的保护；新增设定页集成测试逐个覆盖核心大纲和 6 个更多设定长文本。
- 类型检查、lint、i18n 覆盖率检查全部通过。

升级不改动作品数据。

Windows 安装包未签名，系统可能提示未知发布者。

## English

This release brings the architecture editor's **select text, then edit with AI** workflow to the book setup page.

### Every long-form setup field now supports selection editing

- The core outline plus six long-form fields in More settings — writing style, protagonist, world, core hook, global guidance and references — now support text selection.
- Selecting text shows the same four actions as the architecture editor: **Refine, Expand, Continue and To dialogue**. Both editors share the same action definitions, prompts and reasoning stages.
- AI results are shown as a preview first. The original setup is changed only after you press **Replace**; **Cancel** leaves it untouched.
- If the setup changed while generation was running, the stale result is not applied. The preview remains available to copy and the UI explains why it was not applied.
- Existing typography, input styling, focus behaviour, saving and required-field validation are unchanged. Only the selection toolbar was added.

### Verification

- Full browser regression: 80 test files and 955 tests passed.
- New component tests cover preview, replacement and stale-source protection; a new setup-page integration test covers the core outline and all six long-form More settings fields.
- Typecheck, lint and i18n coverage all pass.

Upgrading does not touch project data.

The Windows installer is not code-signed; Windows may warn about an unknown publisher.
