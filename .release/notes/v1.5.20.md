# 1.5.20

## 中文

- 「一键生成全部剩余细纲」不再打开只能填 10 章的弹框，改为启动连续生成：自动按每批 10 章一直生成到全书结束。
- 细纲一节的「一键生成全部细纲」同样走连续生成。
- 架构页新增「每章约 N 字」输入，开始前可直接调整每章细纲目标字数。
- 连续生成支持暂停、继续、停止；失败会自动重试，进度以实际已保存章节为准。
- 想只生成某一段时，仍可用「选章节范围生成…」，那里按单批限制。

## English

- "Generate all remaining chapter outlines" no longer opens a 10-chapter-only dialog; it starts continuous generation that runs 10-chapter batches until the whole book is done.
- The chapter-outline section button uses the same continuous runner.
- The architecture page now has a per-chapter target input so you can adjust the outline length before starting.
- Continuous generation supports pause, resume and stop, retries failures, and advances by actually saved chapters.
- A single bounded batch is still available from "Choose chapters…".

The Windows installer is not code-signed.
