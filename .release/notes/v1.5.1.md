# 1.5.1

## 中文

修复 1.5.0 中点击「AI 生成粗纲」立即失败的问题。

- 粗纲命令原先传入空的 Prompt Key 集合，主进程在 `generation:begin` 阶段直接拒绝，报 `GENERATION_BEGIN_INVALID`。
- 现在注册了独立的 `arc_outline` 内置 Prompt（中英双语），粗纲生成、反推粗纲、对话式重写粗纲三条路径都使用它。
- 已在真实项目《源起》上验证：粗纲成功生成第 1–60 章一段，并写入粗纲面板。

其它功能与 1.5.0 一致。升级不改动作品数据。

Windows 安装包未签名，系统可能提示未知发布者。

## English

Fixes the immediate failure when clicking **Generate arc outline** in 1.5.0.

- The arc command sent an empty prompt-key set, so the main process rejected `generation:begin` with `GENERATION_BEGIN_INVALID`.
- A dedicated bilingual `arc_outline` built-in prompt is now registered and used by arc generation, deriving from an existing outline, and dialogue-driven arc rewrites.
- Verified on the real 源起 project: the arc outline generated chapter 1-60 and appeared in the arc panel.

All other behavior matches 1.5.0. Upgrading does not touch project data.

The Windows installer is not code-signed; Windows may warn about an unknown publisher.
