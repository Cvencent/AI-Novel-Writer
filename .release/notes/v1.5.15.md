# 1.5.15

## 中文

生成细纲时，模型现在能拿到完整的粗纲依据。

### 细纲生成会带上粗纲

- 一键生成某一批细纲（例如第 1–10 章）时，会把**覆盖这一批的粗纲段全文**注入 prompt，模型必须服从该段的方向与转折。
- 同时注入**全书粗纲索引**（每段的章节区间、标题、形态、是否已确认），模型能判断这一批处在全书什么位置、前面写了什么、后面要接什么。
- 按单个粗纲段生成细纲时，仍然只注入该段全文。
- 细纲生成原本就带故事前提、角色名单、世界观、类型与受众、故事结构、叙事视角、全局写作要求、已有细纲的检索式上下文与最近章节摘要，这些继续保留。
- 细纲生成使用工具循环，模型仍可调用 `read_characters` / `create_character` / `update_character` / `delete_character` / `search_knowledge` / `read_architecture` 主动查资料或调整人物。

## English

Chapter-outline generation now receives the arc outline it depends on.

### Arc context is injected into the chapter-outline prompt

- When generating a batch of chapter outlines (for example chapters 1-10), the **full text of the arc segments covering that batch** is injected, and the model must follow their direction and turning points.
- A **full arc index** is also injected (chapter range, title, beat, confirmed state for every segment), so the model can place the batch in the whole book and see what comes before and after.
- Per-segment generation still injects only that segment in full.
- The existing context remains: premise, cast, worldbuilding, genre and audience, story structure, point of view, global guidance, a bounded retrieval context of already-written chapter outlines, and recent chapter summaries.
- Chapter-outline generation runs a tool loop, so the model can still call read_characters / create_character / update_character / delete_character / search_knowledge / read_architecture to look things up or adjust characters.
