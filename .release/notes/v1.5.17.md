# 1.5.17

## 中文

- 生成粗纲、重写粗纲段、生成细纲三条链路的 prompt 都加入了「核心大纲（全书方向，必须遵守）」。
- 核心大纲取自作品设定页，模型不再只看到故事前提与世界观，减少写偏。

## English

- The core outline is now injected into arc generation, arc-segment rewrite and chapter-outline generation prompts as a book-level direction that must be followed.
- It is read from the setup page, so the model no longer sees only the premise and worldbuilding, reducing drift.

The Windows installer is not code-signed.
