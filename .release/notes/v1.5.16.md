# 1.5.16

## 中文

- 细纲一节新增「一键生成全部细纲」按钮，打开即可调每章字数与章节范围。
- 顶部「一键生成全部剩余细纲」改为打开同一个弹框，不再跳过字数设置。
- 每章细纲默认目标从 600 字下调到 300 字。

## English

- Added a "Generate all chapter outlines" button to the chapter-outline section, opening the dialog where per-chapter length and chapter range can be adjusted.
- The header shortcut now opens the same dialog instead of bypassing the length setting.
- Default per-chapter outline target lowered from 600 to 300 characters.

The Windows installer is not code-signed.
