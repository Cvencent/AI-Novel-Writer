# 1.5.24

## 中文

这一版修正细纲生成“越写越偏”的根因。

### 逐章细纲不再复用旧的“全书细纲”模板
- 旧路径把「整合全书、写结构拐点而非细纲」与「本次只写第 N 章」同时发给模型，两条指令冲突。
- 现在逐章只发送章级合同：核心大纲、故事前提、角色图谱、世界观、全局写作要求，以及全书叙事约束。

### 每章都会带上粗纲
- 注入完整粗纲索引，以及当前章所属粗纲段全文。
- 第 1 章不会再跑到第 2 段（121–300 章）的剧情。

### 细纲重新启用工具循环
- 逐章细纲现在暴露 read_characters / create_character / update_character / delete_character / search_knowledge / read_architecture。
- 模型可以在生成细纲时自主查阅资料、查询角色、新增或修改角色。

### 验证
- 新增章级上下文回归测试。
- 类型检查、lint、i18n 通过。
- 全量浏览器回归：80 个测试文件、958 项全部通过。

升级不改动作品数据。

Windows 安装包未签名，系统可能提示未知发布者。

## English

This release fixes the root cause of drifting chapter outlines.

### Chapter outlines no longer reuse the old whole-book synopsis template
- The old path sent both “integrate the whole book, write structural turning points rather than an outline” and “write only chapter N”, which conflicted.
- Each chapter now receives only its chapter-level contract: core outline, premise, character graph, worldbuilding, global guidance and narrative constraints.

### Every chapter carries its arc outline
- The full arc index plus the owning arc segment are injected.
- Chapter 1 can no longer jump into the second arc segment (chapters 121-300).

### Chapter outlines use the tool loop again
- read_characters / create_character / update_character / delete_character / search_knowledge / read_architecture are exposed.
- The model can consult project data and add or edit characters while writing an outline.

### Verification
- Added chapter-context regression tests.
- Typecheck, lint and i18n pass.
- Full browser regression: 80 files, 958 tests passed.

Upgrading does not touch project data.

The Windows installer is not code-signed.
