# 1.5.11

## 中文

这一版修掉设定页长文本框里选区 AI 浮层跑出视口的问题。

### 浮层跟着真实选区走，不再掉到页面底部

- 长文本框、页面已经向下滚动时，浮层现在按鼠标选区的实际位置定位，不再拿整个文本框的位置硬算。
- 预览比快捷操作高，出现后会按实际尺寸再做一次位置校准，保证「替换」和「取消」始终留在可视区域内。
- 键盘选择、文本框内部滚动、窗口尺寸变化也会重新定位，避免浮层停在一个点不到的位置。
- 设定页和故事架构编辑器使用同一套浮层能力，行为一致。

### 验证

- 新增回归用例：高文本框 + 页面滚动 + 选区落在视口底部，断言预览浮层完整位于视口内。
- 全量浏览器回归：80 个测试文件、958 项全部通过。
- 类型检查、lint、i18n 覆盖率检查全部通过。

升级不改动作品数据。

Windows 安装包未签名，系统可能提示未知发布者。

## English

This release fixes the selection AI toolbar escaping the viewport in tall setup textareas.

### The toolbar now follows the real selection

- In a tall textarea on a scrolled page, the toolbar is positioned from the actual pointer or DOM selection instead of the whole textarea rectangle.
- Previews are taller than the quick actions, so the toolbar is measured again after it renders and shifted back into view. **Replace** and **Cancel** stay clickable.
- Keyboard selection, textarea scrolling and window resizing all reposition the toolbar.
- The setup page and the story architecture editor share the same behaviour.

### Verification

- New regression case: a tall textarea, a scrolled page and a selection near the bottom of the viewport must keep the whole preview toolbar inside the viewport.
- Full browser regression: 80 test files and 958 tests passed.
- Typecheck, lint and i18n coverage all pass.

Upgrading does not touch project data.

The Windows installer is not code-signed; Windows may warn about an unknown publisher.
