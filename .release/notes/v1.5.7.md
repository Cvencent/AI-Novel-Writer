# 1.5.7

## 中文

这一版补上粗纲缺的两个入口，并把「粗纲没写完不许写细纲」这条规则真正落实。

### 架构页里现在能一键生成全部粗纲

- 粗纲的「等我确认 / 跳过确认」和生成按钮过去都只在粗纲面板自己的头部里。而这个面板并进架构页时是**嵌入**模式，嵌入模式下整个头部都不渲染——结果你在架构页上既选不了生成方式，也找不到一键铺满的入口，只能一段一段点「生成下一段」。
- 现在嵌入模式有自己的工具栏：**等我确认 / 跳过确认**两个模式，加上**一键生成全部粗纲**。点它就从下一段开始，一段接一段生成到全书末章，中途自动确认（不需要你逐段点）。
- 粗纲已经铺满全书时，这个按钮自动消失，不会留一个点了没用的控件。

### 粗纲没写完，细纲/大纲生成不了

- 这条规则以前只在「按本段生成全部细纲」那个按钮上生效（要求该段已确认）。但另外两条路径：架构页的「一次生成全部剩余大纲」、以及生成对话框里勾选「情节大纲」，**都不检查粗纲**，可以直接跑。
- 现在闸门加在**工作流启动这一处**（`guardIntent`），所以上面所有入口一并受管，不存在漏网的按钮。拦截时会说清差在哪：
  - 一段粗纲都没有 → 提示先去粗纲生成（并提示可以一键铺满）
  - 粗纲没铺满 → 提示「目前覆盖到第 N 章，全书共 M 章」
  - 粗纲铺满但还有段没确认 → 提示还有几段待确认、从那一段起
- **保留一个例外**：从某个已确认的粗纲段点「按本段生成全部细纲」不受这条限制——那一段本身就是你认可的走向，不需要全书粗纲先铺满。
- 判不出来时不拦：全书总章数还没设、或台账读取失败，都不会因此挡住你。

### 验证

- 浏览器测试 79 文件 / 952 项全过；闸门本身的单元测试 8 项、粗纲面板测试 8 项（含新增的嵌入工具栏 3 项）全过。
- 类型检查、lint、i18n 检查通过。
- 端到端在真实应用里跑了新增场景 `arch-arc-gate`：粗纲只到第 40 章 / 全书 120 章时，架构页能看到「等我确认」「跳过确认」「一键生成全部粗纲」「确认此段」；点生成细纲会被拦下并给出粗纲说明，且没有任何运行被启动。
- 关键行为都做了 red-green 验证（先回退实现确认测试变红，再恢复确认转绿）。

## English

This release adds the two missing arc-outline entry points and actually enforces "no chapter outlines until the arc outline is done".

### The architecture page can now generate every arc segment in one click

- The arc outline's "Wait for me / Skip confirmation" toggles and its generate button used to live only in the arc panel's own header. When that panel is **embedded** in the architecture page, the whole header is not rendered — so on the architecture page you could neither pick a mode nor find a fill-everything entry, and had to click "Next segment" one at a time.
- Embedded mode now has its own toolbar: the **Wait for me / Skip confirmation** modes plus **Generate all arc segments**. It runs from the next segment through the final chapter, auto-confirming as it goes (no per-segment clicking).
- When the arc already covers the whole book, that button disappears rather than sitting there doing nothing.

### Chapter outlines cannot be generated before the arc outline is done

- That rule previously only applied to the per-segment "Generate all chapter outlines" button (which required the segment to be confirmed). Two other paths — "Generate all remaining outline" on the architecture page and ticking "Plot outline" in the generate dialog — **never checked the arc outline** and would just run.
- The gate now sits at the **single workflow-launch seam** (`guardIntent`), so every one of those entry points is covered; there is no button that slips past it. When it blocks, it says exactly what is missing:
  - no arc outline at all → points you to generate it (and mentions the one-click fill)
  - arc outline not covering the book → "currently reaches chapter N of M"
  - arc covers the book but some segments are unconfirmed → how many await confirmation and where they start
- **One deliberate exception**: "Generate all chapter outlines in this segment" from an already-confirmed segment is not gated — that segment is a direction you approved, so the whole-book arc does not need to be complete first.
- It never blocks when it cannot tell: an unset total chapter count or a failed ledger read will not stand in your way.

- Typecheck, lint and i18n checks pass.
- End-to-end in the real app with a new `arch-arc-gate` scenario: with the arc reaching chapter 40 of 120, the architecture page shows "Wait for me", "Skip confirmation", "Generate all arc segments" and "Confirm segment"; generating chapter outlines is blocked with an arc-specific explanation, and no run is started.
