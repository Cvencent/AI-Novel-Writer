# 1.5.22

## 中文

这一版修架构页的一批体验问题。

### 未完成候选可以丢弃
- 世界观、细纲的「上次生成在半途停下」提示条新增「丢弃候选」按钮，点掉后提示消失。
- 只会清掉 partial_arch.json 里的候选与检查点字段，正式内容完全不动。

### 顶部标题不再被压成竖排
- 架构页页头「架构 · N / 5 已确认」在动作区变宽时不再逐字换行。
- 标题区保留最小宽度，动作区不再挤压标题的文字节奏。

### 粗纲段可以收起
- 粗纲列表新增「收起粗纲 / 展开粗纲（N 段）」开关，段数多时先收起来。

### 右侧恢复稿卡片可以移除
- 运行侧页的每张可恢复卡片新增「移除卡片」；只从列表里隐去，正式内容、检查点与运行记录都保留。

### 粗纲与细纲支持多选删除
- 粗纲：勾选任意段后删除，会从最早选中那段起删掉该段及之后所有段，随后可从缺口重新生成。
- 细纲：右侧章节目录可勾选、可全选，一键删除所选章节块，正文与目录同步更新。

### 连续生成不再死循环
- 某一批反复没有推进时（例如一直停在第 9 章），连续生成会停下并说明原因，不再无限重跑同一区间。

### 生成日志能看到给了模型哪些工具
- 细纲生成走工具循环，可用工具包含 read_characters / create_character / update_character / delete_character / search_knowledge / read_architecture；现在会把这份清单写进日志。
- 工具清单原本只注入 system prompt，所以只看 user prompt 时看不到，这不是没给。

### 验证
- 全量浏览器回归：80 个测试文件、958 项全部通过。
- 类型检查、lint、i18n 覆盖率检查全部通过。

升级不改动作品数据。

Windows 安装包未签名，系统可能提示未知发布者。

## English

This release fixes a batch of architecture-page issues.

### Unfinished candidates can be discarded
- The "the last run stopped partway" notice for worldbuilding and chapter outlines now has a Discard candidate button.
- It only clears candidate and checkpoint fields in partial_arch.json; saved content is untouched.

### The header no longer collapses into vertical text
- "Architecture - N / 5 confirmed" no longer wraps one character per line when the action area grows.

### Arc segments can be collapsed
- The arc list has a collapse / expand toggle showing the segment count.

### Recovery cards can be dismissed
- Each recoverable card in the run sheet has Dismiss card; it only hides the card. Saved content, checkpoints and run records are kept.

### Multi-select delete for arc segments and chapter outlines
- Arc: selecting segments deletes the earliest selected one and everything after it, so regeneration can resume from the gap.
- Chapter outline: the right-hand contents supports select-all and deletes the selected chapter blocks from the text.

### Continuous generation no longer loops forever
- If a batch repeatedly fails to advance, continuous generation stops and explains why instead of re-running the same range endlessly.

### The generation log shows which tools the model was given
- Chapter-outline generation runs a tool loop exposing read_characters / create_character / update_character / delete_character / search_knowledge / read_architecture; that list is now written to the log.
- Tools are injected into the system prompt, which is why the user prompt alone never showed them.

### Verification
- Full browser regression: 80 test files and 958 tests passed.
- Typecheck, lint and i18n coverage all pass.

Upgrading does not touch project data.

The Windows installer is not code-signed; Windows may warn about an unknown publisher.
