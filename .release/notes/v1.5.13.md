# 1.5.13

## 中文

框选改写现在还会带上「同一字段里其它已经写定的内容」。

### 改粗纲第 3 段时，模型能看到第 1、2、4 段

- 改写某一个字段时，除了紧邻前后文，还会把同一字段/文档里其它已写内容作为既成事实一并送入 prompt。
- 粗纲：其它分段一起带上，章节区间与走向不会前后打架。
- 情节大纲：其它章的大纲一起带上，不会和已定的章节重复或矛盾。
- 核心大纲、世界观、主角人设等单字段：该字段其它部分也会带上，避免只盯着选中的一句话改。
- 超长文档保留首尾各一半并在中间标注省略，不会把整本书塞进一次请求。
- 与项目权威设定、作用域约束、紧邻上下文一起生效；作者自定义模板删掉占位符时运行时仍会补回。

### 验证

- 全量浏览器回归：80 个测试文件、958 项全部通过。
- 新增后端用例：改粗纲中间一段时，prompt 中同时出现第 1 段与第 3 段内容，并标注为「同一字段里的其它内容（既成事实）」。
- 类型检查、lint、i18n 覆盖率检查全部通过。

升级不改动作品数据。

## English

Selection rewrites now also carry the other written content of the same field.

### Editing arc segment 3 now shows the model segments 1, 2 and 4

- Besides the immediately surrounding text, other written content from the same field or document is supplied as established facts.
- Arc outline: the other segments come along, so chapter ranges and direction cannot contradict each other.
- Plot synopsis: the other chapter outlines come along, so the revision cannot duplicate or conflict with settled chapters.
- Single-field material such as the core outline, world setting or protagonist profile also brings the rest of that field, so the model does not edit one sentence in isolation.
- Very long documents keep the first and last half with an explicit elision marker instead of sending an entire book.
- Works together with the authoritative project settings, scope constraints and immediately adjacent context; the runtime appends them even if a custom template drops the placeholders.

### Verification

- Full browser regression: 80 test files and 958 tests passed.
- New backend coverage: rewriting the middle arc segment puts both the first and the third segment into the prompt, marked as established same-field content.
- Typecheck, lint and i18n coverage all pass.

Upgrading does not touch project data.
