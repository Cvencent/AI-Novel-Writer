# 1.5.3

## 中文

这一版修性能，并把粗纲正式并进架构页。

### 打开作品不再卡

- 打开项目时，主进程会对整个数据库做校验并计算「作者内容指纹」。这个指纹过去把**生成日志表也算进去**：作者越写，日志越大。实测《源起》的 `generation_attempts` 已积累 126 MB，单次校验要 2.7 秒，而打开一次要跑好几遍，累计 43 秒。
- 生成日志是执行遥测，不是作者内容，也不参与任何迁移的字节保护契约，现在已排除在作者内容指纹之外。同一份库的校验耗时降到约 150 毫秒。
- 同一次打开原本会对同一个库重复校验两遍（升级 seam + 准入 seam），现在升级结果直接交给准入复用，只校验一次。
- 实测《源起》（478 MB，508 章大纲）：**打开时间 51 秒 → 5.4 秒**。

### 粗纲并入架构页

- 粗纲现在是架构页的**第四节**，顺序为：故事前提 → 角色名单 → 世界观 → **粗纲** → 情节大纲。
- 这一节与其它节同款：同一个卡片样式、同一个状态徽标、同一句摘要、同一套菜单与操作按钮，不再是浮在上面的独立面板。
- 段列表直接显示在节里（区间、标题、形态、状态），不用先打开别的地方。
- 和世界观、情节大纲一样，点「查看粗纲」会**打开一个标签**，在里面可以看全文分段内容。
- 粗纲按段存在 `arc_outlines` 台账里，因此那个标签是只读的；要改内容请用「改这一段」或「从本章之后重来」。

### 验证

- 在真实《源起》上验证：打开 5.4 秒；五节顺序为 故事前提 / 角色名单 / 世界观 / 粗纲 / 情节大纲；粗纲节显示「2 段 · 已确认 1 段 · 到第 190 章」，段标题与区间直接可见；点「查看粗纲」能打开标签并读到分段全文。
- 类型检查、lint、i18n 检查通过；架构页浏览器测试 31 项、大纲与迁移相关测试 85 项全过。

升级不改动作品数据。

Windows 安装包未签名，系统可能提示未知发布者。

## English

This release fixes performance and folds the arc outline into the architecture page.

### Opening a project is no longer slow

- On open, the main process verifies the whole database and computes an author-content fingerprint. That fingerprint used to include the **generation log tables**, which grow as the author writes. On 源起, `generation_attempts` had reached 126 MB, so a single verification cost 2.7 s and one open ran it several times — 43 s in total.
- Generation logs are execution telemetry, not author content, and no migration's byte-preservation contract references them, so they are now excluded from the author-content fingerprint. Verifying the same database dropped to about 150 ms.
- One open also verified the same database twice (upgrade seam and admission seam). The upgrade result is now handed to admission, so it verifies once.
- Measured on 源起 (478 MB, 508 outline chapters): **open time 51 s → 5.4 s**.

### Arc outline joins the architecture page

- The arc outline is now the **fourth section**: premise → cast → world → **arc outline** → plot outline.
- It matches the other sections: same card styling, same status badge, same summary line, same menu and actions. It is no longer a floating separate panel.
- Segment rows (range, title, beat, status) are shown inline in the section.
- Like worldbuilding and the plot outline, "View arc outline" **opens a tab** where the full segmented text can be read.
- The arc outline lives in the `arc_outlines` ledger, so that tab is read-only; edit through "Revise" or "Regenerate after this chapter".

### Verification

- Verified on the real 源起 project: opens in 5.4 s; section order is premise / cast / world / arc outline / plot outline; the arc section shows "2 segments · 1 confirmed · through ch. 190" with segment titles and ranges inline; "View arc outline" opens a tab with the full segmented text.
- Typecheck, lint and i18n checks pass; 31 architecture browser tests and 85 outline/migration tests pass.

Upgrading does not touch project data.

The Windows installer is not code-signed; Windows may warn about an unknown publisher.
