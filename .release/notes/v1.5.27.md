# 1.5.27

## 中文

### 细纲生成时 AI 新增角色现在能真正写入
- 根因：新版项目使用稳定身份 schema，要求每个角色都有 characterId；但 create_character 工具新建角色时只给了名字，没有分配 ID，提交时被拒：CHARACTER_ID_WRITE_REQUIRED。
- 结果：模型调用了几次 create_character 全部失败，角色表一直是原来的 8 个，大纲里出现的新人物（如沈砚）只停留在文字里。

### 修复
- 新增角色时自动分配 draft:<uuid> 身份，提交后由主进程登记为正式角色 ID（与 UI「新建角色」同一机制）。
- update_character / delete_character 从现有名单读取，自带身份，无需改动。

### 验证
- 纯函数回归：只给名字会自动补 ID；已有 ID 原样保留。
- 端到端回归：在真实稳定身份 schema 项目上走完整提交链路，新角色成功落库。
- 类型检查、lint、i18n 通过。

升级不改动作品数据。
